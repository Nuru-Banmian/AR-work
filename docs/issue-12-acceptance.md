# Issue #12 实施与验证记录

日期：2026-10-26（Asia/Shanghai）。按用户在本对话确认的新方向实现，详见 [设计与操作说明](issue-12-design.md)。原 Issue 的打印定位卡要求由“现场固定标牌/海报登记与自动校准”替代。

## 已实现

- 手机设置新增现场参照入口，填写名称、位置和实测宽高；取景框拍摄图案本体、预览/重拍。保存前验证实际上传 JPEG 的图案特征，不使用整张房间照片估算空间位置。
- 后端持久化图案、尺寸、唯一身份、版本、有效状态与图片哈希；版本不可覆盖，新版本成功保存才停用旧版。重复请求返回原结果，存储失败不改变原数据。
- 参照与未发送草稿按服务绑定；参照资料缓存可用于离线识别。发送后的登记请求持久化冻结，重启后可继续原服务、原正文重试；明确拒绝后可以修正。
- 新增/补定位必须先识别选定参照，跟踪有效后才能选点和拍摄。问题保存参照身份、版本、尺寸和相对点位；不使用旧会话绝对坐标恢复。
- 历史详情先展示所需参照照片、位置和尺寸，用户主动开始扫描后才开相机；恢复位置和方向，跟踪失效隐藏点位。权限拒绝或定位服务启动失败保留明确提示。恢复标记沿用问题状态颜色。
- 旧记录可读，缺定位资料时明确提示现场补定位。补定位保留 ID、创建时间、内容和状态；旧参照停用后不可用于新的定位保存。幂等创建的旧回执仍可确认。
- 已合入用户明确授权的远端 #11 依赖。原有 README、AI_LOG、AGENTS、CONTEXT、docs/agents 和 start.ps1 等工作区内容保留，不纳入 #12 提交。
