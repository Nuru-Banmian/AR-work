# 每条问题独立保存扫描模型

2026-10-27 需求访谈确认：新问题依赖局部扫描表面选点，因此上报资料同时包含现场快照、选点所用的扫描模型及模型内标记。即使多个问题来自同一设备，每条问题仍保存独立的模型副本，不建立共享设备模型关系，以保持单条提交与删除的边界清晰。

重新标记成功后以新位置、新快照和新模型覆盖原资料，清除旧附件，不保留历史版本。问题永久删除时同时删除其快照和模型，不设回收站；用于防止旧请求重复创建的必要去重信息仍需保留。

第二轮访谈确认：文字、快照、模型及标记全部保存成功才算已同步，PC 普通列表仅展示完整提交；手机持久保存完整资料，失败后自动重试。重新标记的新资料全部保存成功后才替换旧资料并清除旧附件，失败仍保留旧资料；问题编号、文字和处理状态保持不变。

提交自动冻结本次选点所用模型及其局部标记位置和方向，不从历史模型库手选。当前范围仅上传问题关联模型，手机独立模型库继续保留，PC 不增加独立模型库。管理端默认展示现场快照，切换至三维模型时加载，支持扫描颜色、圆锥标记、旋转、缩放、平移、复位和标记显隐；模型标记修改通过手机重新标记完成。

2026-10-27 真机验收后，用户将标记形状改为圆锥。手机现场与 PC 模型使用一致的小型圆锥，尖端位于点击点，锥体沿该点表面法线向外伸出；既有现场快照不重写。
