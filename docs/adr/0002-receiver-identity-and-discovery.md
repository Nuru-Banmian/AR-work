# 手动输入接收端地址，以身份保护上传目的地

2026-10-27 用户在真机体验后明确取消自动寻找，改为 PC 上线时显示手机需要输入的实际 API 端口和局域网完整地址，手机手动输入、验证并保存。该决定取代本 ADR 先前的广播发现和后台重发现方案；服务端不再监听发现端口。PC 默认端口占用时仍从有限范围实际绑定备用端口，管理网页自动连接本机服务。

手机同时记住地址与接收端稳定身份。同一接收端换址后由用户输入新地址，HTTP 核对为同一身份后更新路由并继续原冻结请求；不同电脑的旧队列仍绑定原目标，不能自动转发。身份不等于登录或可信设备认证。连接失败提示核对 IP、实际 API 端口、同一局域网和防火墙。
