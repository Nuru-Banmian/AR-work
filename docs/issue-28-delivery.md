2026-10-27，累计验收基线 `9d7561a`。#23–#27 已逐项完成；本页记录最后的集成复验。用户修订优先：**手机手动输入地址，不提供自动发现；标记为圆锥，尖端在点击点，底面直径 2 cm、高 2.5 cm，沿表面外法线伸出**。旧快照保持原样。自动检查、浏览器、真实手机采集及录制资料回放分别列证，不互相替代。

## 启动与连接

Windows 仓库根目录运行：

```powershell
./start.ps1
```

API 首选 18088，网页首选 5176，各在起始端口到 +9 内实际尝试绑定；失败明确报错，不使用其他进程占用的服务。脚本自动打开网页，网页通过同源代理连接本次 API。启动窗口及网页“手机连接”显示实际 API 端口和完整 LAN 地址。多网卡时选择与手机同网段的一条；手机不能使用网页端口。

手机设置输入完整 `http://IP:API端口`，点“连接并保存”。先验证接收端身份再保存，应用重启保留。地址改变后手动输入新地址；同身份更新路由，原冻结正文和幂等键不变。连接失败核对 IP、API 端口、Wi-Fi 与防火墙。不同接收端不会接收原目的地队列；旧队列仅经原地址成功握手绑定身份。不要删除 `receiver.json` 来修复连接。没有 UDP 监听、寻找按钮或后台重发现。协议与端口实测见 [连接说明](receiver-discovery.md)。

默认数据文件 `backend/data/issues.json`，身份文件在同目录；保持两者和现有数据。用 `./start.ps1 -DataFile <隔离目录>/issues.json` 可独立演示，不能把验收目录覆盖到原数据目录。脚本退出只停止自己的子进程。

## 手机上报与重新标记

1. 首页点“新增问题”，进入现场扫描；缓慢移动观察实物局部表面，暂停扫描后在重建表面选点。未观察区域允许缺口，不保证扫描精度或闭合模型。
2. 拍摄现场快照，预览后确认或重拍，填写标题、描述和优先级，再提交。新问题要求本次选点模型与已确认照片，不能从独立模型库假定现场关系。
3. 网络前持久冻结文字、照片、模型、局部点/法线、身份及请求键。离线时保留本地请求；清扫、继续扫描、删除独立模型或进程重启不修改该副本。联网后按原请求重试，完整成功回执前不显示已同步；进度展示实际阶段，不提供虚假百分比。未知结果时保留数据并核对，不能清空重建请求。
4. 详情点“重新标记”，重新扫描、选点、拍摄并确认。一次替换位置、照片、模型和局部标记，编号、文字、优先级、状态保留；并发管理员编辑不被覆盖。明确保存失败时旧完整资料仍可用。回执未知或重启后可进入同问题重试原资料，不能以取消撤销可能已成功的事务。未发送的采集取消不改远端。
5. 独立模型库另存本地模型用于预览，与问题附件独立。应用重启不按历史 AR 世界坐标恢复现场标记；查看旧照片/模型不代表跨会话定位。

接口、32 MiB 完整请求预算、90,000 顶点/160,000 三角形及照片限制见 [模型上传](issue-model-upload.md)；替换/回执语义见 [重新标记](issue-25-remark.md)。旧无模型记录与旧冻结请求继续兼容，不要求重建旧 AR 会话。

## PC 管理与永久删除

顶部统计按全部问题计数，点击全部/待处理/处理中/已解决筛选。工具栏搜索标题或描述，组合状态/优先级，按创建时间、更新时间或优先级排序，显示结果数。空数据与无匹配分别提示。

表格包含照片缩略图。点击问题打开详情，默认现场照片，可打开大图；切换“三维模型”后按需加载彩色表面和圆锥。拖动旋转、右键拖动平移、滚轮缩放；按钮复位、显隐标记或颜色。图片/模型失败可重试，切换记录会释放旧查看器；旧记录明确显示无模型。PC 不编辑模型标记，修改需手机重新标记。

详情可编辑文字、优先级和状态。切换记录、筛选和 SSE 更新保留当前网页会话草稿；整页刷新不承诺草稿持久化。保存期间锁定操作，失败保留输入及错误。SSE 重连后全量查询；Vite 上游中断会结束下游，使 EventSource 能重连，手动刷新仍可兜底。

“永久删除”显示标题及不可恢复提示，输入当前完整标题后确认。成功才从列表/统计/详情移除，失败保留记录。照片、模型、含旧附件的回执/暂存一并清除，仅保留防重放的最小非附件信息。手机依据明确 deletedIds 及匹配身份移除列表、已同步副本、打开详情和当前会话标记，旧创建/替换返回 410 终止重试。独立模型库、其他接收端和其他未上传问题保留。没有回收站、历史版本或物理介质安全擦除承诺。详见 [删除](issue-26-delete.md)、[管理页](issue-27-management.md)。
